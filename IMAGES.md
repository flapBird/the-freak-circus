# Image Placement Guide

Place your images in these directories following the naming convention below.

## Home Page Images
Put images in `public/images/home/`:

| File | Description |
|---|---|
| `about-game.webp` | Game scene / cover art for "What Is" section |
| `characters.webp` | Character group shot or mood art |
| `gameplay.webp` | Gameplay screenshot or how-to-play scene |
| `faq.webp` | FAQ section mood image |

## Character Gallery Images
Put ONE image per character in `public/images/characters/`:

| File | Character |
|---|---|
| `pierrot-1.webp` | Pierrot |
| `harlequin-1.webp` | Harlequin |
| `jester-1.webp` | Jester |
| `doctor-1.webp` | Doctor |
| `columbina-1.webp` | Columbina |
| `ticket-taker-1.webp` | Ticket Taker |

## Community Fan Art
Put images in `public/images/community/`:

| File | Description |
|---|---|
| `fanart-1.webp` through `fanart-4.webp` | Fan art submissions

## Format
WebP preferred. JPG/PNG also supported. Keep files under 500KB.
